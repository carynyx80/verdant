# Implementation sequence
1. Application shell, responsive visual system, wallet connection, fee studio, persistence schema.
2. Fixed-supply token, factory, deterministic virtual reserve market, integer quotes, trading integration.
3. Atomic graduation adapter, permanently locked LP, approved post-graduation router.
4. Immutable fee configuration, isolated accounting, claims and operational authorization.
5. Bounded execution adapters, AI budget/reconciliation and milestone accounting.
6. Confirmed-chain indexer, API, real-event analytics and portfolio reads.
7. Executed tests, CI, local preview, explicit security and integration gaps.

No mainnet contracts will be deployed by this build. Runtime integrations requiring external credentials remain disabled until configured and reviewed.
